# GNIST ✳

GNIST er en social multiplayer-spilplatform til fester. Én stor skærm viser spillet, mens alle andre bruger deres telefon som controller. Opret en fest, del koden, og lad GNIST vælge næste spil tilfældigt.

Efter hver runde vises resultatet med den bedste og dårligste placering. De to nederste får en venlig påmindelse om at tage en tår for holdet. Vinderne samler point gennem hele aftenen, og både rundens og festens samlede leaderboard kan vises.

## Spillene

| Spil | Sådan fungerer det |
| --- | --- |
| **Klikamok** | Tryk så hurtigt som muligt. Spillet vælger selv en tilfældig varighed på 10–45 sekunder. Flest klik vinder. |
| **På sekundet** | Skærmen bliver grøn, og tiden starter automatisk. Stop fra telefonen, når du tror, det tilfældige mål på 1–60 sekunder er nået. Nærmest vinder. |
| **Lynhurtig** | Vent på signalet **NU!** og tryk så hurtigt som muligt. For tidlige tryk tæller som tyvstart. |
| **Hovedbrud** | Løs regnestykket hurtigere end de andre. Korrekte svar rangeres efter svartid. |
| **Tal mønster** | Find det manglende tal i en tilfældig række med fem tal. Spørgsmålstegnet kan stå hvor som helst. |
| **Fang den** | Fang en cirkel, der flytter sig på telefonen, 10 gange. Den samlede tid afgør placeringen. |
| **3×3 Grid** | Tryk tallene 1–9 i rækkefølge. Et forkert tryk blander tallene igen. |
| **Duellen** | To spillere mødes i sten, saks, papir. Uafgjort giver en ny omgang. |
| **Skæbnehjulet** | Hjulet vælger tilfældigt en spiller. Alle følger med på den store skærm. |
| **Tikkende bombe** | Send bomben videre, før den tilfældige lunte på 30–90 sekunder udløber. En modtager skal vente 3 sekunder, før bomben kan sendes videre. |

## Point

I spil med placeringer gives 3 point for førstepladsen, 2 point for andenpladsen og 1 point for tredjepladsen. Resten får 0 point. Ved uafgjort deler spillerne placering og point. Skæbnehjulet og Tikkende bombe giver ikke point.

## Sådan spiller I

Åbn GNIST på den store skærm, opret en fest, og lad vennerne deltage med rumkoden fra deres telefoner. Der kræves ingen app eller brugerkonto.
